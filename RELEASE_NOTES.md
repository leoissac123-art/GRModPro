# GRModPro Horror 1.0.0

This release contains one real Minecraft Bedrock add-on: a hostile `grmodpro:horror` entity with behavior and matching resource-pack visuals.

- Target metadata: Minecraft Bedrock 26.52
- Package: `downloads/GRModPro-Horror-1.0.0.mcaddon`
- Spawn: use the generated spawn egg or `/summon grmodpro:horror` with cheats enabled
- Achievements: **not promised**. Mojang's official guidance states that only Marketplace add-ons qualify for achievements; this direct community download is not a Marketplace add-on.
